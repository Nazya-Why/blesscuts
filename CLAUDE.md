# ТЗ: сайт барбершопу Bless Cuts

Ти будуєш новий односторінковий сайт-лендинг для барбершопу Bless Cuts (Львів). Макет погоджений. Нижче все, що потрібно: стек, дизайн-система, структура, увесь контент, ціни й посилання. Працюй по кроках, після кожного великого кроку запускай `npm run build` і перевіряй, що збірка проходить.

---

## 1. Стек

- **Astro** (статичний сайт, мінімум JS) + **Tailwind CSS**
- TypeScript
- Дані (послуги, ціни, майстри, контакти) — в окремих файлах `src/data/*.ts`, НЕ зашиті в розмітку
- Зображення через `astro:assets` (`<Image />`), формат WebP/AVIF, lazy-loading
- Деплой: Vercel або Netlify (статичний білд)
- Жодних важких бібліотек анімацій: CSS transitions + `IntersectionObserver` для появи блоків

Структура:
```
src/
  data/        services.ts, barbers.ts, contacts.ts
  components/  Header, ThemeToggle, Hero, Stats, About, Services, Barbers,
               Gallery, Certificate, Reviews, Contacts, Footer
  layouts/     Base.astro
  pages/       index.astro
  assets/      logo.png, фото (див. розділ 8)
public/        favicon, og-image.jpg
```

## 2. Дизайн-система

### Стиль
Мінімалізм у дусі Apple: багато повітря, великі заокруглення, м'які картки, без градієнтів і прикрас. Основа білий, сірий і чорний. Орієнтир по відчуттю: сучасні SaaS-дашборди (чисті картки, акуратні таби).

### Шрифт
```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display", "Onest", sans-serif;
```
Onest підключити з Google Fonts (400, 500, 600, 700) — він підхоплюється на не-Apple пристроях. `-webkit-font-smoothing: antialiased`.

### Кольори (CSS-змінні, дві теми)

| Токен | Світла | Темна | Де використовується |
|---|---|---|---|
| `--bg` | #FFFFFF | #000000 | фон сторінки |
| `--section` | #F5F5F7 | #0E0E10 | фон сірих секцій (Про нас, Майстри, Контакти) |
| `--card` | #F5F5F7 | #1C1C1E | картки на фоні `--bg` |
| `--card-on-section` | #FFFFFF | #1C1C1E | картки всередині сірих секцій |
| `--text` | #1D1D1F | #F5F5F7 | основний текст |
| `--text-2` | #6E6E73 | #98989D | другорядний текст, підписи |
| `--text-3` | #424245 | #C7C7CC | текст абзаців |
| `--border` | #E5E5EA | #2C2C2E | рамки, розділювачі |
| `--btn-bg` | #1D1D1F | #F5F5F7 | головна кнопка |
| `--btn-text` | #FFFFFF | #000000 | текст головної кнопки |
| `--tab-active` | #FFFFFF | #3A3A3C | активний таб |
| `--brand-black` | #000000 | #000000 | футер і картка сертифіката (під лого) |

Фон `html` і `body` під футером завжди **#000000** (щоб при «пружинистому» скролі на iPhone не вилазив білий).

### Темна тема
- За замовчуванням береться з системи (`prefers-color-scheme`)
- У шапці кнопка-перемикач (іконка сонце/місяць, `aria-label`), вибір зберігається в `localStorage`
- Скрипт вибору теми інлайном у `<head>`, щоб не було спалаху білого при завантаженні
- У темній темі картка сертифіката отримує рамку `1px solid #2C2C2E`, футер отримує `border-top: 1px solid #1C1C1E`

### Розміри й форми
- Контейнер: `max-width: 1200px`, бокові відступи 24px (мобільні 16px)
- Вертикальні відступи секцій: 112px десктоп / 48px мобільні
- Радіуси: великі картки 28–32px, картки 20–24px, фото 14–16px, кнопки і таби `999px` (пігулки)
- Кнопки: мінімальна висота 44px
- Заголовки H2: 48px десктоп / 32px мобільні, `font-weight: 700`, `letter-spacing: -0.03em`, `line-height: 1.08`
- H1 (hero): 72px десктоп / 44px мобільні, `letter-spacing: -0.035em`
- Надзаголовки секцій («ПОСЛУГИ ТА ЦІНИ»): 14px, 600, `letter-spacing: 0.08em`, колір `--text-2`
- Іконки: інлайн SVG зі штрихом, без емодзі

### Анімації (плавні, ненав'язливі)
- Поява блоків при скролі: `opacity 0→1`, `translateY(24px)→0`, `0.9s cubic-bezier(.2,.8,.2,1)`
- Картки при наведенні: `translateY(-4px)` + м'яка тінь `0 18px 40px rgba(0,0,0,.08)`, `0.5s`
- Кнопки при наведенні: `scale(1.02)`, `0.3s`
- Таби: плавна зміна фону й кольору `0.35s`
- Рядки прайсу при наведенні: легкий фон `--card`
- Шапка: sticky, напівпрозора з `backdrop-filter: saturate(180%) blur(20px)`
- Обов'язково поважати `prefers-reduced-motion: reduce` — вимикати всі анімації

## 3. Структура сторінки (по порядку)

> **Оновлено 01.10.2026 за UX-розбором:** порядок блоків змінено з «презентації» на «продаж»: результат і довіра → послуги → майстер → докази → запис. Кожен великий блок закінчується кнопкою запису, і всі такі кнопки однотипні: «Записатися онлайн» (у картці майстра — «Записатися до {ім'я}»). Рейтинг і кількість відгуків — `rating` і `reviewCount` у `contacts.ts`, на сайті кількість показується округленою: «1 000+».

1. **Шапка (sticky)** — зліва текстовий логотип «BLESS CUTS» (700, `letter-spacing: 0.08em`; ЛОГО-КАРТИНКУ В ШАПЦІ НЕ СТАВИТИ), по центру меню-якорі (Чому ми, Ціни, Майстри, Відгуки, Контакти — `src/data/nav.ts`), справа перемикач теми і кнопка «Записатися». На мобільних: текстовий логотип, кнопка «Запис», бургер (відкриває повноекранне меню).
2. **Hero (кінематографічний, оновлено 01.10.2026)** — фоном на весь екран (`min-height: clamp(560px, 100svh, 960px)`) відео залу: на портретних екранах вертикальне `src/assets/video/hero.mp4`, на альбомних — `hero-wide.mp4` (центральна смуга того самого відео, заздалегідь збільшена до 1920×1080 Lanczos + різкість, CRF 23, ~4,7 МБ; обкладинка `hero-video-wide.jpg`); джерело обирає скрипт за орієнтацією, під відео — `<picture>` з обкладинкою потрібної орієнтації, з рівномірним затемненням `rgb(0 0 0 / .55)` (без градієнтів), заходить під шапку. Відео: 720×1280, 9,4 с, без звуку, ~1,5 МБ; підрізане там, де камера повертається до першого кадру, тож повтор без шва; підключене через `?url` — у назві файлу хеш, кеш не заважає оновленню; обкладинка `src/assets/hero-video.jpg` з preload високого пріоритету. Відео стартує через ~1,2 с після завантаження сторінки (коли браузер вільний), грає тільки коли видиме, не грає при «зменшити рух», економії трафіку чи 2G. Поверх відео — без `backdrop-filter`. Поверх, унизу зліва, білим: дві пігулки в ряд — «★ 5,0 · 1 000+ відгуків у Google» і живий статус «● Відкрито до 20:00» / «● Відкриємось о 10:00» (зелений блимаючий маячок / помаранчева точка, `data-format="short"`), H1 «Барбершоп у центрі Львова.», підзаголовок (що + де + скільки майстрів + ціна від), кнопки «Записатися онлайн» (біла) і «Ціни» (напівпрозора). Під кнопками нічого — дрібні рядки-підписи там не ставити. Шапка над фото прозора з білим текстом (клас `is-over-hero`), після фото — звичайна.
3. **Статистика (trust bar)** — 4 картки (на мобільних 2×2): «5,0 — 1 000+ відгуків у Google», «8 — майстрів, 6 рівнів досвіду», «від 500 ₴ — чоловіча стрижка», інвертована картка з адресою.
4. **Чому Bless Cuts** (сіра секція, `#why`) — фото + H2 «Тут не тільки про стрижку.», одне речення й 4 конкретні причини: рейтинг, 8 майстрів / 6 рівнів, центр Львова, запис без дзвінків. Без маркетингової «води».
5. **Ціни** (`#services`) — H2 «Скільки коштує стрижка.», 4 картки популярних послуг з цінами «від …» (`popular: true` у `services.ts`), далі доступні таби рівнів (`role="tablist"`, стрілки, Home/End; мобільні 2×3, планшет 3×2, десктоп один ряд). У панелі спочатку лише популярні послуги, решта — за кнопкою «Показати весь прайс» (стан спільний для всіх рівнів; без JS прайс показується повністю). Під списком «Майстри цього рівня: …» і «Записатися».
6. **Майстри** (сіра секція) — картки: фото, рівень, ім'я, пігулки «сильні сторони» (`focus` у `barbers.ts`), «Стрижка — {ціна рівня}», кнопка «Записатися до {ім'я в родовому відмінку}». Десктоп 4 в ряд, **мобільні 2 колонки, усі 8 видно без горизонтального гортання** (кнопка просто «Записатися»). Над сіткою підбір «Що тобі потрібно?» — кнопки-фільтри (`needs` у `barbers.ts`: борода, довге волосся, класика, сміливі форми, новий образ, тренди + автоматично «Стрижка за {мін. ціна} ₴»), показують лише відповідних майстрів (`aria-pressed`, статус для скрінрідерів; без JS не показуються). Під сіткою смуга «Не знаєш, кого обрати?» з кнопкою запису.
7. **Вперше у нас?** — 4 кроки (обери майстра → послугу → час → приходь) і кнопка запису.
8. **Відгуки** (сіра секція, `#reviews`) — велике «5,0 з 5», зірки, «1 000+ відгуків у Google.», кнопки «Записатися онлайн» і «Читати відгуки» (Google Maps). Тексти відгуків НЕ вигадувати — додавати лише справжні, обрані власником.
9. **Галерея** — «Атмосфера Bless Cuts.»: сітка 4 колонки, перше фото велике (2×2), на мобільних 2 колонки; під нею «Записатися онлайн» і «Роботи майстрів в Instagram». Коли будуть фото результатів / до-після — винести окремим блоком «Наші роботи» вище.
10. **Сертифікат** — окремий чорний блок: «Не знаєш, що подарувати?», «Подаруй чоловікові не річ, а новий образ…», плашки «Діє 4 місяці» і «Будь-яка послуга», кнопка «Замовити сертифікат» → Instagram; справа зображення картки-сертифіката з лого.
11. **FAQ** (сіра секція) — розкривні `<details>` з `src/data/faq.ts`, лише питання з точно відомими відповідями.
12. **Контакти** — зліва картки: телефон (`tel:`), Instagram, години роботи, «Подивись вхід і зал у 3D» (`tourUrl`); справа карта Google Maps (`iframe`, `loading="lazy"`) з адресою і «Прокласти маршрут →».
13. **Закріплена кнопка «Записатися онлайн»** внизу екрана на телефонах і планшетах — з'являється, коли кнопки hero прокручені, ховається біля футера.
14. **Футер** — чорний (#000). По центру велике лого (≈420px десктоп / 300px мобільні), слоган «Твій стиль — наше мистецтво.», кнопка «Записатися онлайн» (біла), пігулки-посилання: Instagram, TikTok, 3D-тур, Відгуки Google (`socials` у `contacts.ts`). Під лінією-розділювачем: копірайт і живий статус «Зараз відкрито · до 20:00 / Зараз зачинено» за київським часом. Кнопки «Нагору» немає — нагору веде логотип у шапці. Меню-якорі, адресу й телефон у футері НЕ дублювати — вони вже в шапці й у контактах.

## 4. Контент

Тексти живуть у компонентах і `src/data/*.ts`; цифри (рейтинг, кількість майстрів, ціни «від») беруться з даних, не пишуться вручну.

### Hero
- H1: **Барбершоп у центрі Львова.**
- Підзаголовок: Чоловічі стрижки, борода й камуфлювання сивини на площі Данила Галицького. 8 майстрів, стрижка — від 500 ₴.

### Чому Bless Cuts
- Надзаголовок: ЧОМУ BLESS CUTS · H2: Тут не тільки про стрижку.
- Речення: Традиційні техніки й сучасний барберинг — з 2023 року в самому центрі Львова.
- Причини: 5,0 у Google · 8 майстрів (6 рівнів, досвід під бюджет) · Центр Львова · Запис без дзвінків.

### Сертифікат
- Надзаголовок: ПОДАРУНКОВИЙ СЕРТИФІКАТ · H2: Не знаєш, що подарувати?
- Текст: Подаруй чоловікові не річ, а новий образ. Сертифікат на будь-яку послугу — від стрижки до догляду за бородою.
- Плашки: Діє 4 місяці · Будь-яка послуга
- Кнопка: «Замовити сертифікат» → Instagram барбершопу (`contacts.instagramUrl`, у новій вкладці)

### Секційні заголовки
- Ціни: «ПОСЛУГИ ТА ЦІНИ» / «Скільки коштує стрижка.» / «Ціна залежить від досвіду барбера. Усі ціни в гривнях.»
- Майстри: «МАЙСТРИ» / «Обери свого барбера.»
- Вперше у нас: «ВПЕРШЕ У НАС?» / «Чотири кроки до нової стрижки.»
- Відгуки: «ВІДГУКИ» / «1 000+ відгуків у Google.»
- Галерея: «ГАЛЕРЕЯ» / «Атмосфера Bless Cuts.»
- FAQ: «ЧАСТІ ПИТАННЯ» / «Коротко про головне.»
- Контакти: «КОНТАКТИ» / «Чекаємо на тебе.»

### Чого бракує (потрібні матеріали від барбершопу)
- Фото результатів і «до / після» з іменем майстра; коротке відео атмосфери (10–20 с).
- Підтверджені спеціалізації майстрів: `focus` і `needs` (підбір «Що тобі потрібно?») зараз узято з їхніх описів.
- Instagram кожного майстра (якщо є) — для кнопки в картці.
- Фото входу з вулиці (поки є лише 3D-тур у контактах).
- Справжні відгуки, обрані власником, для карток відгуків.
- FAQ: чи можна прийти без запису, скільки триває стрижка, чи треба мити голову перед стрижкою.

## 9. SEO і технічне

- `<html lang="uk">`, title: «Bless Cuts — барбершоп у центрі Львова | Чоловіча стрижка», description з адресою, цінами «від 500 ₴», кількістю майстрів і рейтингом; H1 «Барбершоп у центрі Львова.»
- Open Graph і Twitter-картки (`og-image.jpg`)
- Structured data JSON-LD типу `BarberShop`: назва, адреса, телефон, геокоординати, години (`Mo-Su 10:00-20:00`), `aggregateRating` (5.0, `reviewCount` з `contacts.ts`), `priceRange`, посилання на Instagram, TikTok і запис
- `sitemap.xml`, `robots.txt`, favicon з лого (ножиці або «BC»)
- `theme-color` окремо для світлої й темної теми
- Lighthouse: ціль 95+ по всіх пунктах на мобільних
- Доступність: реальні `<button>` і `<a>`, `alt` у всіх фото, видимий фокус, контраст тексту не менше 4.5:1, плавний скрол до якорів з урахуванням висоти sticky-шапки (`scroll-margin-top`)
- Адаптив: перевірити на 375, 390, 768, 1024, 1440px, без горизонтального скролу
